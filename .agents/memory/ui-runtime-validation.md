---
name: Проверка UI-патчей
description: Как проверять изменения React/Vite и диагностировать сбои на экране проекта.
---

После изменений React-интерфейса проверяйте TypeScript отдельно от Vite build: сборка может пройти, даже если JSX обращается к необъявленному имени, которое падает только при рендере.

**Why:** ошибка в подписи таймлайна прошла Vite build и проявилась при открытии проекта; typecheck выявил несовпадение имени переменной. Preview-снимок открывает портфель без входа и не проверяет защищённый экран проекта.

**How to apply:** запускайте typecheck и build после изменений UI. Если runtime-лог неполный, проверяйте авторизованный сценарий проекта отдельно; не считайте чистый снимок страницы портфеля подтверждением, что проектная страница работает.

Успешный браузерный тест с перехваченными ответами API подтверждает только рендер и взаимодействия на тестовых данных, но не исправность сохранённого пользовательского проекта или настоящего входа.

**Why:** сбой после входа не воспроизвёлся на корректной тестовой модели; это не доказывает, что исходная ошибка устранена.

**How to apply:** явно указывайте границы такой проверки и не объявляйте невоспроизведённое падение исправленным без исходного сообщения или воспроизводящего действия.
