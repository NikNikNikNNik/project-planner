---
name: Удаление проектов
description: Пользовательская граница для удаления проектов в планировщике.
---

Сохранять возможность удалять проекты. Удалять проекты только по прямому запросу пользователя; без запроса не выполнять удаление, включая массовое.

**Why:** пользователь попросил сохранить возможность удалять проекты по его запросу.

**How to apply:** перед удалением проверить, что пользователь явно просит удалить конкретные проекты, и не затрагивать остальные.
