---
name: Доступ в приложение
description: Пользовательская модель общего входа и важные ограничения проверки сессий.
---

Использовать одну общую пару логин/пароль для входа во всё приложение, не отдельные учётные данные на каждый проект.

**Why:** пользователь попросил добавить пару для входа именно в приложение после отказа от прежней защиты отдельных проектов.

**How to apply:** получать значения только через защищённую форму, не сохранять их в коде, заметках или истории Git. Не вводить регистрацию и персональные аккаунты без нового запроса.

Проверять успешный вход на собранном сервере с настоящим PostgreSQL-хранилищем сессий, а не ограничиваться тестами с MemoryStore.

**Why:** модульные проверки проходили, но сборка нарушила загрузку служебного SQL-файла библиотеки; проблема проявилась только при создании первой настоящей сессии.

**How to apply:** браузерные проверки проводить с временными настройками тестового процесса, не читая пользовательские секреты; после проверки восстанавливать обычный запуск. Проверять вход, обновление страницы, выход и отказ старой сессии после выхода.
