---
name: Доступ в приложение
description: Требование открытого доступа к приложению без логина и пароля.
---

Приложение должно открываться без логина и пароля. Не возвращать общий или отдельный для проектов экран входа без нового прямого запроса.

**Why:** пользователь прямо попросил удалить вход в приложение по паролю после его добавления.

**How to apply:** интерфейс и API проектов не должны требовать авторизации; не удалять проекты или их данные вместе с механизмом входа.
