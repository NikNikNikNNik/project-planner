---
name: Доступ в приложение
description: Открытый доступ без логина и пароля.
---

Приложение должно открываться без логина и пароля. Не возвращать общий или отдельный для проектов экран входа без нового прямого запроса.

**Why:** после настройки двух учётных записей пользователь прямо попросил убрать вход по логину и паролю.

**How to apply:** интерфейс и API проектов не должны требовать авторизации; удаление механизма входа не должно менять проекты и их содержимое.
