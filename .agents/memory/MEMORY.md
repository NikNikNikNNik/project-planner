- [Календарные даты в API](calendar-dates-api.md) — для плановых дат сохраняйте строки `YYYY-MM-DD`; формат даты в OpenAPI может вызывать нежелательное преобразование в `Date`.
- [Удаление проектов](project-deletion.md) — сохранять удаление доступным, но выполнять его только по прямому запросу пользователя.
- [Проверка UI-патчей](ui-runtime-validation.md) — Vite build может не поймать ошибки имён в JSX; запускайте TypeScript typecheck и проверяйте авторизованный экран.
- [Python-пакеты в PNPM-монорепо](python-package-side-effects.md) — временная установка Python-пакета может изменить `.replit` и создать корневые Python-файлы.
- [Исторические планы обучения](historical-training-data.md) — календарные даты источников сдвигаются на 10 лет; неизвестные сроки и назначения нельзя выдавать за подтверждённые.
- [ФОТ проекта](payroll-policy.md) — месячная ставка на человека в тенге; накопление от индивидуального контракта, ориентиры Атырау остаются предварительными.
- [Оценки стоимости обучения](training-cost-estimates.md) — бюджет события считается по слушателям; индивидуальные курсы и стажировки явно помечаются как ориентиры.
- [ResizeObserver и runtime overlay](resize-observer-overlay.md) — обновляйте состояние по измерениям ширины через animation frame; цикл ResizeObserver может выглядеть как падение приложения.
- [GitHub: доступ через Git](github-git-access.md) — недоступный API-коннектор и неавторизованный gh не означают, что Git-транспорт Replit не работает.
- [Названия профессий на таймлайне](timeline-role-names.md) — полные названия переносить внутри левого столбца для всех цехов, не увеличивая его ширину.
- [Доступ в приложение](application-access.md) — пользователь отменил общий вход по логину и паролю; не возвращать его без нового запроса.
