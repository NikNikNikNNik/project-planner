---
name: GitHub: доступ через Git
description: Различие между авторизацией GitHub API, GitHub CLI и Git-транспортом Replit.
---

Не считать отсутствие GitHub-подключения в API sandbox или авторизации `gh` доказательством отсутствия доступа для `git`.

**Why:** после подключения аккаунта Git-транспорт Replit работал через защищённый внутренний GitHub-прокси, хотя API sandbox не предоставлял подключение и GitHub CLI оставался неавторизованным.

**How to apply:** когда пользователь указал целевой репозиторий, проверить его через `git ls-remote` с отключённым интерактивным запросом пароля. Использовать обычный push без force и сохранять служебные remotes Replit. Не извлекать токены и не угадывать новые идентификаторы OAuth-карточек после отказа официального handle.
